## Typogrify

- Typogrify will incorrectly try to convert alt-text time signatures into fractions. There are Unicode references for time signatures (https://www.w3.org/2019/03/smufl13/tables/time-signatures.html) but in testing they’re not read by screen readers, so defeats the point.

## Modernize spelling

- “Bar-bell” left as is, as it refers to a bell in a bar, not a ”barbell.”
